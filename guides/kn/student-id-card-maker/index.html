ಮುಖಪುಟ/ಮಾರ್ಗದರ್ಶಿಗಳು/ವಿದ್ಯಾರ್ಥಿ ID ಕಾರ್ಡ್ ಮೇಕರ್
ಉಚಿತ, ಸುಲಭ ಮಾರ್ಗದರ್ಶಿ

ವಿದ್ಯಾರ್ಥಿ ID ಕಾರ್ಡ್ ಮೇಕರ್: ID ಕಾರ್ಡ್‌ಗಳನ್ನು ಉಚಿತವಾಗಿ ತಯಾರಿಸಿ A4 ನಲ್ಲಿ ಪ್ರಿಂಟ್ ಮಾಡಿ

ಚಿಕ್ಕ ಶಾಲೆ, ಕೋಚಿಂಗ್ ಕ್ಲಾಸ್ ಅಥವಾ ಒಂದು ಕಾರ್ಯಕ್ರಮಕ್ಕೆ ID ಕಾರ್ಡ್ ತಯಾರಿಸಲು ಡಿಸೈನ್ ಸಾಫ್ಟ್‌ವೇರ್ ಬೇಕಿಲ್ಲ. ಈ ಉಚಿತ ಆ್ಯಪ್ ನೀವು ಬರೆದ ವಿವರಗಳಿಂದ ಕಾರ್ಡ್ ತಯಾರಿಸುತ್ತದೆ; ಮಕ್ಕಳ ಫೋಟೋಗಳು ನಿಮ್ಮ ಸಾಧನದಿಂದ ಹೊರಗೆ ಹೋಗುವುದಿಲ್ಲ.

ಅಪ್‌ಡೇಟ್: 14 ನವೆಂಬರ್ 2026 · ಓದಲು 4 ನಿಮಿಷ

🪪 ID ಕಾರ್ಡ್ ಮೇಕರ್ ತೆರೆಯಿರಿ (ಉಚಿತ) ಹಂತಗಳನ್ನು ನೋಡಿ ↓

ಸಂಕ್ಷಿಪ್ತ ಉತ್ತರ

ID ಕಾರ್ಡ್ ಮೇಕರ್ ತೆರೆದು, “ವಿದ್ಯಾರ್ಥಿ” ಆಯ್ಕೆಮಾಡಿ, ಶಾಲೆಯ ಹೆಸರು ಮತ್ತು ವಿದ್ಯಾರ್ಥಿಯ ವಿವರಗಳನ್ನು ಬರೆಯಿರಿ. ಫೋಟೋ ಸೇರಿಸಲು “ಫೋಟೋ ಆಯ್ಕೆ ಮಾಡಿ” ಒತ್ತಿ. ಇಡೀ ತರಗತಿಗೆ “ಹಲವು ಕಾರ್ಡ್‌ಗಳು (ಪಟ್ಟಿ)” ಆಯ್ಕೆಮಾಡಿ ಪಟ್ಟಿಯನ್ನು ಪೇಸ್ಟ್ ಮಾಡಿ. ನಂತರ “A4 ನಲ್ಲಿ ಮುದ್ರಿಸಿ” ಒತ್ತಿ: ಪ್ರತಿ ಕಾರ್ಡ್ 54 × 86 mm; ಒಂದು A4 ಶೀಟ್‌ನಲ್ಲಿ 9 ಲಂಬ ಅಥವಾ 10 ಅಡ್ಡ ಕಾರ್ಡ್‌ಗಳು ಹಿಡಿಯುತ್ತವೆ.

5 ಹಂತಗಳಲ್ಲಿ ವಿದ್ಯಾರ್ಥಿ ID ಕಾರ್ಡ್

  1. ಕಾರ್ಡ್ ಬಗೆಯನ್ನು ಆಯ್ಕೆಮಾಡಿ, ಶಾಲೆಯ ವಿವರ ತುಂಬಿ

    ID ಕಾರ್ಡ್ ಮೇಕರ್ ತೆರೆಯಿರಿ. ಅದು ಮಾದರಿ ವಿವರಗಳೊಂದಿಗೆ ತೆರೆಯುತ್ತದೆ. “ವಿದ್ಯಾರ್ಥಿ” ಆಯ್ಕೆಮಾಡಿ (“ಸಿಬ್ಬಂದಿ” ಮತ್ತು “ಅತಿಥಿ” ಕೂಡ ಇವೆ). ಶಾಲೆಯ ಹೆಸರು, ವಿಳಾಸ, ಸಂಪರ್ಕ ಸಂಖ್ಯೆ ಮತ್ತು ಕಾರ್ಡ್ ಎಲ್ಲಿಯವರೆಗೆ ಮಾನ್ಯ ಎಂಬುದನ್ನು ಬರೆಯಿರಿ. ಲೋಗೋ ಇದ್ದರೆ “ಲೋಗೋ ಆಯ್ಕೆ ಮಾಡಿ” ಒತ್ತಿ.

  2. ವಿದ್ಯಾರ್ಥಿಯ ವಿವರ ಮತ್ತು ಫೋಟೋ ಸೇರಿಸಿ

    “ಒಂದು ಕಾರ್ಡ್” ಆಯ್ಕೆಯಲ್ಲಿ ಇರುವಾಗ, ಹೆಸರು, ತರಗತಿ ಮತ್ತು ವಿಭಾಗ, ID ಸಂಖ್ಯೆ ಬರೆಯಿರಿ. ರಕ್ತದ ಗುಂಪು ಕಾರ್ಡ್‌ನಲ್ಲಿ ಬೇಕಿದ್ದರೆ ಅದನ್ನು ಆಯ್ಕೆಮಾಡಿ. “ಫೋಟೋ ಆಯ್ಕೆ ಮಾಡಿ” ಒತ್ತಿ, ಮುಖ ಸ್ಪಷ್ಟವಾಗಿರುವ ಫೋಟೋ ಆಯ್ಕೆಮಾಡಿ, ಮುಖ ಫ್ರೇಮ್‌ನ ಮಧ್ಯಕ್ಕೆ ಬರುವವರೆಗೆ ಸ್ಲೈಡರ್‌ಗಳನ್ನು ಸರಿಸಿ.

  3. ಇಡೀ ತರಗತಿಗೆ ಕಾರ್ಡ್ ತಯಾರಿಸಿ

    “ಹಲವು ಕಾರ್ಡ್‌ಗಳು (ಪಟ್ಟಿ)” ಆಯ್ಕೆಮಾಡಿ, ಪ್ರತಿ ಸಾಲಿನಲ್ಲಿ ಒಬ್ಬ ವಿದ್ಯಾರ್ಥಿಯನ್ನು ಬರೆಯಿರಿ ಅಥವಾ ಪೇಸ್ಟ್ ಮಾಡಿ: ಹೆಸರು, ತರಗತಿ, ID ಸಂಖ್ಯೆ, ರಕ್ತದ ಗುಂಪು, ಎಲ್ಲಿಯವರೆಗೆ ಮಾನ್ಯ, ಸಂಪರ್ಕ, ವಿಳಾಸ. ಹೆಸರು ಮಾತ್ರ ಕಡ್ಡಾಯ; Excel ನಿಂದಲೂ ಪೇಸ್ಟ್ ಮಾಡಬಹುದು. “ಮಾದರಿ CSV ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ” ಮೂಲಕ ವಿನ್ಯಾಸ ಅರ್ಥವಾಗುತ್ತದೆ. ಫೋಟೋ ಫೈಲ್‌ಗಳಿಗೆ ID ಸಂಖ್ಯೆ ಅಥವಾ ಹೆಸರನ್ನು ಫೈಲ್ ಹೆಸರಾಗಿ ಇಟ್ಟು, “ಫೋಟೋಗಳನ್ನು ಸೇರಿಸಿ” ನಿಂದ ಎಲ್ಲವನ್ನೂ ಒಟ್ಟಿಗೆ ಸೇರಿಸಿ.

  4. ವಿನ್ಯಾಸ ಆಯ್ಕೆಮಾಡಿ

    “ಉದ್ದ” ಅಥವಾ “ಅಡ್ಡ” ಮತ್ತು ಒಂದು ಬಣ್ಣ ಆಯ್ಕೆಮಾಡಿ. ID ಸಂಖ್ಯೆ ಇರುವ QR ಕೋಡ್ ಬೇಕಿದ್ದರೆ “ID ಸಂಖ್ಯೆಯ QR ಕೋಡ್ ಸೇರಿಸಿ” ಅನ್ನು ಟಿಕ್ ಮಾಡಿ.

  5. A4 ನಲ್ಲಿ ಪ್ರಿಂಟ್ ಮಾಡಿ ಅಥವಾ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ

    “A4 ನಲ್ಲಿ ಮುದ್ರಿಸಿ” ಒತ್ತಿ. ಪ್ರಿಂಟ್ ವಿಂಡೋದಲ್ಲಿ A4 ಕಾಗದ ಮತ್ತು 100% ಸ್ಕೇಲ್ ಆಯ್ಕೆಮಾಡಿ, ನಂತರ ಚಿಕ್ಕ ಗುರುತುಗಳ ಉದ್ದಕ್ಕೂ ಕತ್ತರಿಸಿ. “PNG ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ” ಕಾರ್ಡ್ ಅನ್ನು ಚಿತ್ರವಾಗಿ ಸೇವ್ ಮಾಡುತ್ತದೆ.

ID ಕಾರ್ಡ್ ಪ್ರಿಂಟ್ ಮಾಡಲು ಸಲಹೆಗಳು

  • ದಪ್ಪ A4 ಕಾಗದದಲ್ಲಿ ಪ್ರಿಂಟ್ ಮಾಡಿ. ನಂತರ ಕಾರ್ಡ್‌ಗಳನ್ನು ಲ್ಯಾಮಿನೇಟ್ ಮಾಡಿಸಿ ಅಥವಾ ಕಾರ್ಡ್ ಹೋಲ್ಡರ್‌ಗಳಲ್ಲಿ ಇಡಿ.
  • ಇನ್ನೂ ಫೋಟೋ ಇಲ್ಲವೇ? ಕಾರ್ಡ್‌ನಲ್ಲಿ ಸುಮಾರು 20 × 25 mm ಖಾಲಿ ಫ್ರೇಮ್ ಬರುತ್ತದೆ; ಅಲ್ಲಿ ಸ್ಟ್ಯಾಂಪ್ ಸೈಜ್ ಫೋಟೋ ಅಂಟಿಸಬಹುದು.
  • ಒಂದು ಪಟ್ಟಿಯಲ್ಲಿ 300 ಕಾರ್ಡ್‌ಗಳವರೆಗೆ ತಯಾರಿಸಬಹುದು. ದೊಡ್ಡ ಶಾಲೆಗೆ ಪ್ರತಿ ತರಗತಿಗೂ ಬೇರೆ ಪಟ್ಟಿ ಮಾಡಿ.
  • ಇಡೀ ಶೀಟ್ ಪ್ರಿಂಟ್ ಮಾಡುವ ಮೊದಲು ಪರದೆಯಲ್ಲಿ ಕಾಗುಣಿತ, ID ಸಂಖ್ಯೆ ಮತ್ತು ಸಂಪರ್ಕ ಸಂಖ್ಯೆಯನ್ನು ಪರಿಶೀಲಿಸಿ. ಒಂದು ID ಸಂಖ್ಯೆ ಎರಡು ಸಲ ಬಂದರೆ ಆ್ಯಪ್ ತಿಳಿಸುತ್ತದೆ.

ಹೊಸ ಉಚಿತ ಟೂಲ್‌ಗಳು ಮತ್ತು ಹಿಂದಿಯಲ್ಲಿ AI ಪಾಠಗಳನ್ನು ಪಡೆಯಿರಿ

ನಮ್ಮ ಇಮೇಲ್ ಪಟ್ಟಿಗೆ ಸೇರಿ: ಹೊಸ ಉಚಿತ ಆ್ಯಪ್‌ಗಳು, ಹೊಸ ಮಾರ್ಗದರ್ಶಿಗಳು ಮತ್ತು AI ಕುರಿತ ಹಿಂದಿ ವೀಡಿಯೊ ಪಾಠಗಳ ಮಾಹಿತಿ ನಿಮಗೆ ಬರುತ್ತದೆ. ಸ್ಪ್ಯಾಮ್ ಇಲ್ಲ.

ನಾವು ಈ ಟೂಲ್‌ಗಳನ್ನು ಏಕೆ ಸೂಚಿಸುತ್ತೇವೆ

  • ಎಲ್ಲರಿಗೂ ಉಚಿತ: ಜಾಹೀರಾತು ಇಲ್ಲ, ಸೈನ್-ಅಪ್ ಇಲ್ಲ, ಪಾವತಿ ಯೋಜನೆ ಇಲ್ಲ.
  • ಖಾಸಗಿ: ನಿಮ್ಮ ಫೈಲ್‌ಗಳು ಮತ್ತು ವಿವರಗಳು ನಿಮ್ಮ ಸ್ವಂತ ಸಾಧನದಲ್ಲೇ ಇರುತ್ತವೆ.
  • ಫೋನ್, ಲ್ಯಾಪ್‌ಟಾಪ್ ಅಥವಾ ಸ್ಮಾರ್ಟ್‌ಬೋರ್ಡ್‌ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತವೆ, ಒಮ್ಮೆ ತೆರೆದ ನಂತರ ಇಂಟರ್ನೆಟ್ ಇಲ್ಲದೆಯೂ.
  • ಕನ್ನಡ ಮತ್ತು ಹಿಂದಿ ಸೇರಿದಂತೆ 12 ಭಾಷೆಗಳಲ್ಲಿ.

ID ಕಾರ್ಡ್‌ನ ಅಳತೆ ಎಷ್ಟು?

ಪ್ರತಿ ಕಾರ್ಡ್ 54 × 86 mm; ಸುಮಾರು ಬ್ಯಾಂಕ್ ಕಾರ್ಡ್‌ನಷ್ಟು. ಆದ್ದರಿಂದ ಸಾಮಾನ್ಯ ಕಾರ್ಡ್ ಹೋಲ್ಡರ್‌ಗಳಲ್ಲಿ ಹಿಡಿಯುತ್ತದೆ. ಈ ಅಳತೆ ಉಳಿಯಲು 100% ಸ್ಕೇಲ್‌ನಲ್ಲಿ ಪ್ರಿಂಟ್ ಮಾಡಿ.

ಒಂದು A4 ಪುಟದಲ್ಲಿ ಎಷ್ಟು ID ಕಾರ್ಡ್ ಹಿಡಿಯುತ್ತವೆ?

9 ಲಂಬ ಕಾರ್ಡ್ ಅಥವಾ 10 ಅಡ್ಡ ಕಾರ್ಡ್. ನಿಮ್ಮ ಪಟ್ಟಿಗೆ ಎಷ್ಟು ಪುಟ ಬೇಕು ಎಂದು ಆ್ಯಪ್ ತೋರಿಸುತ್ತದೆ.

ಎಲ್ಲ ವಿದ್ಯಾರ್ಥಿಗಳಿಗೂ ಒಂದೇ ಸಲ ID ಕಾರ್ಡ್ ತಯಾರಿಸಬಹುದೇ?

ಹೌದು. “ಹಲವು ಕಾರ್ಡ್‌ಗಳು (ಪಟ್ಟಿ)” ಆಯ್ಕೆಮಾಡಿ ಪಟ್ಟಿಯನ್ನು ಪೇಸ್ಟ್ ಮಾಡಿ, ಅಥವಾ “CSV ಫೈಲ್ ತೆರೆಯಿರಿ” ನಿಂದ CSV ಫೈಲ್ ತೆರೆಯಿರಿ. ಎಲ್ಲ ಫೋಟೋಗಳನ್ನು ಒಟ್ಟಿಗೆ ಸೇರಿಸಿ: ID ಸಂಖ್ಯೆ ಅಥವಾ ಹೆಸರಿನ ಮೂಲಕ ಅವು ತಾವೇ ಹೊಂದಿಕೊಳ್ಳುತ್ತವೆ.

ವಿದ್ಯಾರ್ಥಿಗಳ ಫೋಟೋಗಳು ಅಪ್‌ಲೋಡ್ ಆಗುತ್ತವೆಯೇ?

ಇಲ್ಲ. ಫೋಟೋಗಳು ಮತ್ತು ವಿವರಗಳು ನಿಮ್ಮ ಸಾಧನದಲ್ಲೇ ಇರುತ್ತವೆ; ಏನೂ ಅಪ್‌ಲೋಡ್ ಆಗುವುದಿಲ್ಲ. ಕಾರ್ಡ್‌ಗಳು ನಿಮ್ಮ ಸ್ವಂತ ಬ್ರೌಸರ್‌ನಲ್ಲೇ ತಯಾರಾಗುತ್ತವೆ.

ಇದು ಸರ್ಕಾರಿ ಗುರುತಿನ ಚೀಟಿಯೇ?

ಇದು ನಿಮ್ಮ ಸ್ವಂತ ಶಾಲೆ, ಕ್ಲಾಸ್, ಕಚೇರಿ ಅಥವಾ ಕಾರ್ಯಕ್ರಮದ ಗುರುತಿನ ಚೀಟಿ. ಇದು ಸರ್ಕಾರಿ ID ಅಲ್ಲ; ಇದನ್ನು ಶಾಲೆ ಅಥವಾ ಆಯೋಜಕರು ಮಾತ್ರ ತಯಾರಿಸಬೇಕು.
