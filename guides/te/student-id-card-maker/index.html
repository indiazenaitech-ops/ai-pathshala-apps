ఉచిత, సులభమైన గైడ్

విద్యార్థి ID కార్డ్ మేకర్: ID కార్డులు ఉచితంగా తయారు చేసి A4 పై ప్రింట్ చేయండి

చిన్న పాఠశాల, కోచింగ్ క్లాస్ లేదా ఒక కార్యక్రమానికి ID కార్డులు తయారు చేయడానికి డిజైన్ సాఫ్ట్‌వేర్ అవసరం లేదు. ఈ ఉచిత యాప్ మీరు రాసిన వివరాల నుంచి కార్డును తయారు చేస్తుంది; పిల్లల ఫోటోలు మీ డివైస్ దాటి వెళ్లవు.

అప్‌డేట్: 14 నవంబర్ 2026 · చదవడానికి 4 నిమిషాలు

🪪 ID కార్డ్ మేకర్ తెరవండి (ఉచితం) దశలు చూడండి ↓

సంక్షిప్త సమాధానం

ID కార్డ్ మేకర్ తెరిచి, “విద్యార్థి” ఎంచుకుని, పాఠశాల పేరు, విద్యార్థి వివరాలు రాయండి. ఫోటో చేర్చడానికి “ఫోటో ఎంచుకోండి” నొక్కండి. తరగతి మొత్తానికి “చాలా కార్డులు (జాబితా)” ఎంచుకుని జాబితాను పేస్ట్ చేయండి. తర్వాత “A4 పై ప్రింట్ చేయండి” నొక్కండి: ప్రతి కార్డు 54 × 86 mm; ఒక A4 షీట్‌పై 9 నిలువు లేదా 10 అడ్డం కార్డులు పడతాయి.

5 దశల్లో విద్యార్థి ID కార్డులు

  1. కార్డు రకాన్ని ఎంచుకుని, పాఠశాల వివరాలు నింపండి

    ID కార్డ్ మేకర్ తెరవండి. అది నమూనా వివరాలతో తెరుచుకుంటుంది. “విద్యార్థి” ఎంచుకోండి (“సిబ్బంది”, “అతిథి” కూడా ఉన్నాయి). పాఠశాల పేరు, చిరునామా, సంప్రదింపు నంబర్, కార్డు ఎప్పటివరకు చెల్లుతుందో రాయండి. లోగో ఉంటే “లోగో ఎంచుకోండి” నొక్కండి.

  2. విద్యార్థి వివరాలు, ఫోటో చేర్చండి

    “ఒక కార్డు” ఎంపికలో ఉండగా, పేరు, తరగతి మరియు సెక్షన్, ID నంబర్ రాయండి. బ్లడ్ గ్రూప్ కార్డుపై కావాలంటే దాన్ని ఎంచుకోండి. “ఫోటో ఎంచుకోండి” నొక్కి, ముఖం స్పష్టంగా ఉన్న ఫోటో ఎంచుకుని, ముఖం ఫ్రేమ్ మధ్యలోకి వచ్చేవరకు స్లైడర్లను జరపండి.

  3. తరగతి మొత్తానికి కార్డులు తయారు చేయండి

    “చాలా కార్డులు (జాబితా)” ఎంచుకుని, ప్రతి వరుసలో ఒక విద్యార్థిని రాయండి లేదా పేస్ట్ చేయండి: పేరు, తరగతి, ID నంబర్, బ్లడ్ గ్రూప్, ఎప్పటివరకు చెల్లుతుంది, సంప్రదింపు, చిరునామా. పేరు మాత్రమే తప్పనిసరి; Excel నుంచి కూడా పేస్ట్ చేయవచ్చు. “నమూనా CSV డౌన్‌లోడ్ చేయండి” ద్వారా అమరిక అర్థమవుతుంది. ఫోటో ఫైళ్లకు ID నంబర్ లేదా పేరును ఫైల్ పేరుగా పెట్టి, “ఫోటోలు జోడించండి” తో అన్నీ ఒకేసారి చేర్చండి.

  4. డిజైన్ ఎంచుకోండి

    “నిలువు” లేదా “అడ్డం”, ఒక రంగు ఎంచుకోండి. ID నంబర్ ఉన్న QR కోడ్ కావాలంటే “ID నంబర్ QR కోడ్ జోడించండి” ను టిక్ చేయండి.

  5. A4 పై ప్రింట్ చేయండి లేదా డౌన్‌లోడ్ చేయండి

    “A4 పై ప్రింట్ చేయండి” నొక్కండి. ప్రింట్ విండోలో A4 కాగితం, 100% స్కేల్ ఎంచుకుని, చిన్న గుర్తుల వెంట కత్తిరించండి. “PNG డౌన్‌లోడ్ చేయండి” కార్డును చిత్రంగా సేవ్ చేస్తుంది.

ID కార్డులు ప్రింట్ చేయడానికి చిట్కాలు

  • మందమైన A4 కాగితంపై ప్రింట్ చేయండి. తర్వాత కార్డులను లామినేట్ చేయించండి లేదా కార్డ్ హోల్డర్లలో పెట్టండి.
  • ఇంకా ఫోటో లేదా? కార్డుపై సుమారు 20 × 25 mm ఖాళీ ఫ్రేమ్ వస్తుంది; అక్కడ స్టాంప్ సైజు ఫోటో అతికించవచ్చు.
  • ఒక జాబితాలో 300 కార్డుల వరకు తయారు చేయవచ్చు. పెద్ద పాఠశాలకు ప్రతి తరగతికి వేరే జాబితా చేయండి.
  • షీట్ మొత్తం ప్రింట్ చేసే ముందు స్క్రీన్‌పై స్పెల్లింగ్, ID నంబర్లు, సంప్రదింపు నంబర్ సరిచూడండి. ఒక ID నంబర్ రెండుసార్లు వస్తే యాప్ చెబుతుంది.

ID కార్డు సైజు ఎంత?

ప్రతి కార్డు 54 × 86 mm; దాదాపు బ్యాంక్ కార్డు అంత. కాబట్టి సాధారణ కార్డ్ హోల్డర్లలో సరిపోతుంది. ఈ సైజు మారకుండా ఉండటానికి 100% స్కేల్‌లో ప్రింట్ చేయండి.

ఒక A4 పేజీలో ఎన్ని ID కార్డులు పడతాయి?

9 నిలువు కార్డులు లేదా 10 అడ్డం కార్డులు. మీ జాబితాకు ఎన్ని పేజీలు కావాలో యాప్ చూపిస్తుంది.

విద్యార్థులందరికీ ఒకేసారి ID కార్డులు తయారు చేయవచ్చా?

అవును. “చాలా కార్డులు (జాబితా)” ఎంచుకుని జాబితాను పేస్ట్ చేయండి, లేదా “CSV ఫైల్ తెరవండి” తో CSV ఫైల్ తెరవండి. ఫోటోలన్నీ ఒకేసారి చేర్చండి: ID నంబర్ లేదా పేరు ఆధారంగా అవి వాటంతట అవే జతపడతాయి.

విద్యార్థుల ఫోటోలు అప్‌లోడ్ అవుతాయా?

లేదు. ఫోటోలు, వివరాలు మీ డివైస్‌లోనే ఉంటాయి; ఏదీ అప్‌లోడ్ కాదు. కార్డులు మీ సొంత బ్రౌజర్‌లోనే తయారవుతాయి.

ఇది ప్రభుత్వ గుర్తింపు కార్డా?

ఇది మీ సొంత పాఠశాల, క్లాస్, ఆఫీసు లేదా కార్యక్రమం యొక్క గుర్తింపు కార్డు. ఇది ప్రభుత్వ ID కాదు; దీన్ని పాఠశాల లేదా నిర్వాహకులు మాత్రమే తయారు చేయాలి.
