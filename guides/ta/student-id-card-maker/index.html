மாணவர் ID அட்டை உருவாக்கி: இலவசமாக ID அட்டை உருவாக்கி A4-இல் அச்சிடுங்கள்

சிறிய பள்ளி, பயிற்சி வகுப்பு அல்லது ஒரு நிகழ்ச்சிக்கு ID அட்டை உருவாக்க வடிவமைப்பு மென்பொருள் தேவையில்லை. இந்த இலவசச் செயலி நீங்கள் எழுதும் விவரங்களிலிருந்து அட்டையை உருவாக்குகிறது; குழந்தைகளின் புகைப்படங்கள் உங்கள் சாதனத்தை விட்டு வெளியே செல்வதில்லை.

சுருக்கமான பதில்

ID கார்டு மேக்கர் திறந்து, “மாணவர்” தேர்ந்தெடுத்து, பள்ளியின் பெயரையும் மாணவரின் விவரங்களையும் எழுதுங்கள். புகைப்படம் சேர்க்க “புகைப்படத்தைத் தேர்ந்தெடு” அழுத்துங்கள். முழு வகுப்புக்கு “பல கார்டுகள் (பட்டியல்)” தேர்ந்தெடுத்துப் பட்டியலை ஒட்டுங்கள். பிறகு “A4-இல் அச்சிடு” அழுத்துங்கள்: ஒவ்வோர் அட்டையும் 54 × 86 mm; ஒரு A4 தாளில் 9 நெடுக்கு அல்லது 10 கிடை அட்டைகள் அடங்கும்.

5 படிகளில் மாணவர் ID அட்டை

  1. அட்டை வகையைத் தேர்ந்தெடுத்து, பள்ளி விவரங்களை நிரப்புங்கள்

    ID கார்டு மேக்கர் திறங்கள். அது மாதிரி விவரங்களுடன் திறக்கும். “மாணவர்” தேர்ந்தெடுங்கள் (“ஊழியர்”, “விருந்தினர்” ஆகியவையும் உள்ளன). பள்ளியின் பெயர், முகவரி, தொடர்பு எண், அட்டை எதுவரை செல்லும் என்பதை எழுதுங்கள். லோகோ இருந்தால் “லோகோவைத் தேர்ந்தெடு” அழுத்துங்கள்.

  2. மாணவரின் விவரங்களையும் புகைப்படத்தையும் சேருங்கள்

    “ஒரு கார்டு” தேர்வில் இருக்கும்போது, பெயர், வகுப்பு மற்றும் பிரிவு, ID எண் ஆகியவற்றை எழுதுங்கள். இரத்த வகை அட்டையில் வேண்டுமென்றால் அதைத் தேர்ந்தெடுங்கள். “புகைப்படத்தைத் தேர்ந்தெடு” அழுத்தி, முகம் தெளிவாகத் தெரியும் படத்தைத் தேர்ந்தெடுத்து, முகம் சட்டத்தின் நடுவில் வரும் வரை ஸ்லைடர்களை நகர்த்துங்கள்.

  3. முழு வகுப்புக்கும் அட்டைகள் உருவாக்குங்கள்

    “பல கார்டுகள் (பட்டியல்)” தேர்ந்தெடுத்து, ஒவ்வொரு வரியிலும் ஒரு மாணவரை எழுதுங்கள் அல்லது ஒட்டுங்கள்: பெயர், வகுப்பு, ID எண், இரத்த வகை, எதுவரை செல்லும், தொடர்பு, முகவரி. பெயர் மட்டுமே கட்டாயம்; Excel-இலிருந்தும் ஒட்டலாம். “மாதிரி CSV பதிவிறக்கு” மூலம் அமைப்பைப் புரிந்துகொள்ளலாம். படக் கோப்புகளுக்கு ID எண் அல்லது பெயரைக் கோப்புப் பெயராக வைத்து, “புகைப்படங்களைச் சேர்” மூலம் எல்லாவற்றையும் ஒன்றாகச் சேருங்கள்.

  4. வடிவமைப்பைத் தேர்ந்தெடுங்கள்

    “நெடுக்கு” அல்லது “கிடை” மற்றும் ஒரு நிறத்தைத் தேர்ந்தெடுங்கள். ID எண் கொண்ட QR குறியீடு வேண்டுமென்றால் “ID எண்ணின் QR குறியீட்டைச் சேர்” என்பதைக் குறியிடுங்கள்.

  5. A4-இல் அச்சிடுங்கள் அல்லது பதிவிறக்குங்கள்

    “A4-இல் அச்சிடு” அழுத்துங்கள். அச்சு சாளரத்தில் A4 தாளையும் 100% அளவையும் தேர்ந்தெடுத்து, பிறகு சிறிய குறிகளின் வழியே வெட்டுங்கள். “PNG பதிவிறக்கு” அட்டையைப் படமாகச் சேமிக்கும்.

ID அட்டை அச்சிடுவதற்கான குறிப்புகள்

  • தடிமனான A4 தாளில் அச்சிடுங்கள். பிறகு அட்டைகளை லேமினேட் செய்யுங்கள் அல்லது அட்டை உறைகளில் வையுங்கள்.
  • இன்னும் புகைப்படம் இல்லையா? அட்டையில் சுமார் 20 × 25 mm அளவில் ஒரு காலிச் சட்டம் வரும்; அங்கே ஸ்டாம்ப் அளவுப் படத்தை ஒட்டலாம்.
  • ஒரு பட்டியலில் 300 அட்டைகள் வரை உருவாக்கலாம். பெரிய பள்ளிக்கு ஒவ்வொரு வகுப்புக்கும் தனிப் பட்டியல் உருவாக்குங்கள்.
  • முழுத் தாளையும் அச்சிடும் முன் திரையில் எழுத்துப்பிழை, ID எண், தொடர்பு எண் ஆகியவற்றைச் சரிபாருங்கள். ஒரு ID எண் இருமுறை வந்தால் செயலி தெரிவிக்கும்.

புதிய இலவசக் கருவிகளும் இந்தியில் AI பாடங்களும் பெறுங்கள்

எங்கள் மின்னஞ்சல் பட்டியலில் சேருங்கள்: புதிய இலவசச் செயலிகள், புதிய வழிகாட்டிகள், AI பற்றிய இந்தி வீடியோ பாடங்கள் பற்றிய தகவல் உங்களுக்கு வரும். ஸ்பேம் இல்லை.

ID அட்டையின் அளவு என்ன?

ஒவ்வோர் அட்டையும் 54 × 86 mm; ஏறக்குறைய வங்கி அட்டையின் அளவு. எனவே வழக்கமான அட்டை உறைகளில் பொருந்தும். இந்த அளவு மாறாமல் இருக்க 100% அளவில் அச்சிடுங்கள்.

ஒரு A4 பக்கத்தில் எத்தனை ID அட்டைகள் அடங்கும்?

9 நெடுக்கு அட்டைகள் அல்லது 10 கிடை அட்டைகள். உங்கள் பட்டியலுக்கு எத்தனை பக்கங்கள் தேவை என்பதைச் செயலி காட்டும்.

எல்லா மாணவர்களுக்கும் ஒரே நேரத்தில் ID அட்டை உருவாக்க முடியுமா?

ஆம். “பல கார்டுகள் (பட்டியல்)” தேர்ந்தெடுத்துப் பட்டியலை ஒட்டுங்கள், அல்லது “CSV கோப்பைத் திற” மூலம் CSV கோப்பைத் திறங்கள். எல்லாப் படங்களையும் ஒன்றாகச் சேருங்கள்: ID எண் அல்லது பெயரைக் கொண்டு அவை தானாகவே பொருத்தப்படும்.

மாணவர்களின் புகைப்படங்கள் பதிவேற்றப்படுகின்றனவா?

இல்லை. படங்களும் விவரங்களும் உங்கள் சாதனத்திலேயே இருக்கும்; எதுவும் பதிவேற்றப்படாது. அட்டைகள் உங்கள் சொந்த உலாவியிலேயே உருவாகின்றன.

இது அரசு அடையாள அட்டையா?

இது உங்கள் சொந்தப் பள்ளி, வகுப்பு, அலுவலகம் அல்லது நிகழ்ச்சியின் அடையாள அட்டை. இது அரசு ID அல்ல; இதைப் பள்ளி அல்லது ஏற்பாட்டாளர் மட்டுமே உருவாக்க வேண்டும்.
