স্টুডেন্ট ID কার্ড মেকার: বিনামূল্যে ID কার্ড বানিয়ে A4-এ প্রিন্ট করুন

ছোট স্কুল, কোচিং ক্লাস বা কোনো অনুষ্ঠানের ID কার্ড বানাতে ডিজাইন সফটওয়্যার লাগে না। এই বিনামূল্যের অ্যাপ আপনার লেখা তথ্য থেকে কার্ড বানিয়ে দেয়, আর বাচ্চাদের ছবি আপনার ডিভাইসের বাইরে যায় না।

আপডেট: 14 নভেম্বর 2026 · পড়তে 4 মিনিট

🪪 ID কার্ড মেকার খুলুন (বিনামূল্যে) ধাপগুলো দেখুন ↓

সংক্ষেপে উত্তর

ID কার্ড মেকার খুলুন, “ছাত্রছাত্রী” বেছে নিন আর স্কুলের নাম ও ছাত্রছাত্রীর তথ্য লিখুন। ছবি দিতে “ছবি বেছে নিন” চাপুন। পুরো ক্লাসের জন্য “অনেক কার্ড (তালিকা)” বেছে নিয়ে তালিকা পেস্ট করুন। তারপর “A4-এ ছাপুন” চাপুন: প্রতিটি কার্ড 54 × 86 mm, আর এক A4 শিটে 9টি খাড়া বা 10টি আড়াআড়ি কার্ড ধরে।

5 ধাপে স্টুডেন্ট ID কার্ড

  1. কার্ডের ধরন বেছে স্কুলের তথ্য লিখুন

    ID কার্ড মেকার খুলুন। এটা নমুনা তথ্য নিয়ে খোলে। “ছাত্রছাত্রী” বেছে নিন (“কর্মী” আর “অতিথি”-ও আছে)। স্কুলের নাম, ঠিকানা, যোগাযোগের নম্বর আর কার্ড কত দিন পর্যন্ত বৈধ তা লিখুন। লোগো থাকলে “লোগো বেছে নিন” চাপুন।

  2. ছাত্রছাত্রীর তথ্য আর ছবি যোগ করুন

    “একটি কার্ড” বাছা অবস্থায় নাম, শ্রেণি ও সেকশন আর ID নম্বর লিখুন। রক্তের গ্রুপ কার্ডে চাইলে সেটা বেছে নিন। “ছবি বেছে নিন” চাপুন, মুখের একটা পরিষ্কার ছবি বেছে নিন আর মুখ ফ্রেমের মাঝখানে না আসা পর্যন্ত স্লাইডার সরান।

  3. পুরো ক্লাসের কার্ড বানান

    “অনেক কার্ড (তালিকা)” বেছে নিন আর প্রতি লাইনে একজন করে লিখুন বা পেস্ট করুন: নাম, শ্রেণি, ID নম্বর, রক্তের গ্রুপ, কত দিন বৈধ, যোগাযোগ, ঠিকানা। শুধু নামটাই বাধ্যতামূলক, আর Excel থেকেও পেস্ট করা যায়। “নমুনা CSV ডাউনলোড করুন” থেকে ছকটা বোঝা যায়। ছবির ফাইলের নাম ID নম্বর বা নাম অনুযায়ী দিন আর “ছবি যোগ করুন” দিয়ে সব একসঙ্গে যোগ করুন।

  4. ডিজাইন বেছে নিন

    “লম্বা” বা “আড়াআড়ি” আর একটা রং বেছে নিন। ID নম্বরের QR কোড চাইলে “ID নম্বরের QR কোড যোগ করুন”-এ টিক দিন।

  5. A4-এ প্রিন্ট করুন বা ডাউনলোড করুন

    “A4-এ ছাপুন” চাপুন। প্রিন্ট উইন্ডোতে A4 কাগজ আর 100% স্কেল বেছে নিন, তারপর ছোট দাগ বরাবর কাটুন। “PNG ডাউনলোড করুন” দিয়ে কার্ডটা ছবি হিসেবে সেভ হয়।

ID কার্ড ছাপার পরামর্শ

  • মোটা A4 কাগজে ছাপুন। তারপর কার্ড ল্যামিনেট করুন বা কার্ড হোল্ডারে রাখুন।
  • এখনো ছবি নেই? কার্ডে প্রায় 20 × 25 mm মাপের একটা ফাঁকা ফ্রেম আসে, সেখানে স্ট্যাম্প সাইজ ছবি সেঁটে দিতে পারেন।
  • একটা তালিকায় 300টি পর্যন্ত কার্ড হয়। বড় স্কুলের জন্য প্রতিটি ক্লাসের আলাদা তালিকা বানান।
  • পুরো শিট ছাপার আগে স্ক্রিনে বানান, ID নম্বর আর যোগাযোগের নম্বর মিলিয়ে নিন। কোনো ID নম্বর দুবার এলে অ্যাপ জানিয়ে দেয়।

ID কার্ডের মাপ কত?

প্রতিটি কার্ড 54 × 86 mm, প্রায় ব্যাঙ্ক কার্ডের মাপের, তাই সাধারণ কার্ড হোল্ডারে ধরে যায়। এই মাপ ঠিক রাখতে 100% স্কেলে ছাপুন।

এক A4 পাতায় কটা ID কার্ড ধরে?

9টি খাড়া কার্ড বা 10টি আড়াআড়ি কার্ড। আপনার তালিকার জন্য কটা পাতা লাগবে, অ্যাপ তা দেখিয়ে দেয়।

সব ছাত্রছাত্রীর ID কার্ড কি একসঙ্গে বানানো যায়?

হ্যাঁ। “অনেক কার্ড (তালিকা)” বেছে নিয়ে তালিকা পেস্ট করুন, বা “CSV ফাইল খুলুন” দিয়ে CSV ফাইল খুলুন। সব ছবি একসঙ্গে যোগ করুন: ID নম্বর বা নাম ধরে সেগুলো নিজে থেকেই মিলে যায়।

ছাত্রছাত্রীদের ছবি কি আপলোড হয়?

না। ছবি আর তথ্য আপনার ডিভাইসেই থাকে; কিছুই আপলোড হয় না। কার্ড আপনার নিজের ব্রাউজারেই তৈরি হয়।

এটা কি সরকারি পরিচয়পত্র?

এটা আপনার নিজের স্কুল, ক্লাস, অফিস বা অনুষ্ঠানের পরিচয়পত্র। এটা সরকারি ID নয়, আর এটা শুধু স্কুল বা আয়োজকেরই বানানো উচিত।
