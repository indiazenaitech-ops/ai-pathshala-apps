ହୋମ୍/ଗାଇଡ୍/କୃତିଦେବରୁ ୟୁନିକୋଡ୍
ମାଗଣା, ସହଜ ଗାଇଡ୍

କୃତିଦେବକୁ ୟୁନିକୋଡ୍‌କୁ କିପରି ବଦଳାଇବେ (ଓ ଫେରସ୍ତ)

ପୁରୁଣା କୃତିଦେବ ଫାଇଲ୍ ଫୋନ୍ ଓ ୱେବସାଇଟରେ “fd;k” ଭଳି ଦେଖାଯାଏ, କାରଣ ଏହି ଫଣ୍ଟ ଇଂରାଜୀ ଅକ୍ଷର ଉପରେ କେବଳ ହିନ୍ଦୀର ଆକାର ଆଙ୍କେ। ୟୁନିକୋଡ୍‌କୁ ବଦଳାଇଲେ ଏହା ପ୍ରକୃତ ହିନ୍ଦୀ ଲେଖା ହୋଇଯାଏ, ଯାହା WhatsApp, Google Docs, ଇମେଲ୍ ଓ ସର୍ଚ୍ଚରେ ଚାଲେ।

ଅପଡେଟ୍: 4 ଅକ୍ଟୋବର 2026 · ପଢ଼ିବାକୁ 4 ମିନିଟ୍

🔤 କୃତିଦେବ - ୟୁନିକୋଡ୍ କନଭର୍ଟର ଖୋଲନ୍ତୁ (ମାଗଣା) ପଦକ୍ଷେପ ଦେଖନ୍ତୁ ↓

ସଂକ୍ଷିପ୍ତ ଉତ୍ତର

କୃତିଦେବ - ୟୁନିକୋଡ୍ କନଭର୍ଟର ଖୋଲନ୍ତୁ, “କୃତିଦେବ → ୟୁନିକୋଡ୍” ରହିବାକୁ ଦିଅନ୍ତୁ ଏବଂ ଆପଣଙ୍କ କୃତିଦେବ ଲେଖା ପେଷ୍ଟ କରନ୍ତୁ। ୟୁନିକୋଡ୍ ହିନ୍ଦୀ ତୁରନ୍ତ ଆସେ: “ଫଳାଫଳ କପି କରନ୍ତୁ” କିମ୍ବା “.txt ଡାଉନଲୋଡ୍” ଦବାନ୍ତୁ। କୌଣସି ଅଫିସ୍ କିମ୍ବା ପ୍ରେସ୍‌କୁ କୃତିଦେବ ଦରକାର ହେଲେ “ୟୁନିକୋଡ୍ → କୃତିଦେବ” ବାଛନ୍ତୁ।

5ଟି ପଦକ୍ଷେପରେ କୃତିଦେବରୁ ୟୁନିକୋଡ୍

  1. କୃତିଦେବ ଲେଖା କପି କରନ୍ତୁ

    ଆପଣଙ୍କ ପୁରୁଣା Word କିମ୍ବା PageMaker ଫାଇଲ୍ ଖୋଲନ୍ତୁ, ଲେଖା ସିଲେକ୍ଟ (Ctrl+A) ଓ କପି (Ctrl+C) କରନ୍ତୁ। ଲମ୍ବା .txt ଫାଇଲ୍ ହେଲେ ତାହାକୁ ସିଧାସଳଖ କନଭର୍ଟରରେ ଖୋଲିପାରିବେ।

  2. କନଭର୍ଟର୍ ଖୋଲନ୍ତୁ

    କୃତିଦେବ - ୟୁନିକୋଡ୍ କନଭର୍ଟର ଖୋଲି ଦେଖନ୍ତୁ “କୃତିଦେବ → ୟୁନିକୋଡ୍” ବଛାଯାଇଛି କି ନାହିଁ। ପ୍ରଥମେ ଉଦାହରଣ ଦେଖିବାକୁ ଚାହିଁଲେ “ନମୁନା” ଦବାନ୍ତୁ।

  3. ଲେଖା ପେଷ୍ଟ କରନ୍ତୁ

    ଲେଖା ବାକ୍ସରେ ପେଷ୍ଟ କରନ୍ତୁ। ୟୁନିକୋଡ୍ ଫଳ ତୁରନ୍ତ ଦେଖାଯାଏ। ଲାଲ୍ ଚିହ୍ନ ସେହି ଅକ୍ଷରରେ ଥାଏ ଯାହା ବଦଳିପାରିଲା ନାହିଁ ଓ ହାତରେ ଯାଞ୍ଚ କରିବାକୁ ପଡ଼ିବ।

  4. ଇଂରାଜୀ ଶବ୍ଦ ଯେପରି ଅଛି ସେପରି ରଖନ୍ତୁ

    ଆପଣଙ୍କ ଚିଠିରେ ହିନ୍ଦୀ ସହ ଇଂରାଜୀରେ ନାମ, ଇମେଲ୍ କିମ୍ବା ଫାଇଲ୍ ନମ୍ବର ଥିଲେ “ଇଂରାଜୀ ଶବ୍ଦ, ସଂଖ୍ୟା, ଇମେଲ ଓ ଲିଙ୍କ ଯେମିତି ଅଛି ସେମିତି ରଖନ୍ତୁ” ଚାଲୁ କରନ୍ତୁ, ଯାହାଫଳରେ ସେହି ଅଂଶ ବଦଳିବ ନାହିଁ।

  5. ଫଳ କପି କିମ୍ବା ଡାଉନଲୋଡ୍ କରନ୍ତୁ

    “ଫଳାଫଳ କପି କରନ୍ତୁ” ଦବାଇ ଯେକୌଣସି ଜାଗାରେ ପେଷ୍ଟ କରନ୍ତୁ, କିମ୍ବା “.txt ଡାଉନଲୋଡ୍” ଦବାନ୍ତୁ। Wordରେ Mangal, Nirmala UI କିମ୍ବା Noto Sans Devanagari ଭଳି ୟୁନିକୋଡ୍ ଫଣ୍ଟ ରଖନ୍ତୁ।

କୃତିଦେବ ଓ ୟୁନିକୋଡ୍ ମଧ୍ୟରେ ପାର୍ଥକ୍ୟ କ'ଣ?

  • Kruti Dev 010 ଏକ ପୁରୁଣା ଫଣ୍ଟ: କମ୍ପ୍ୟୁଟର ଇଂରାଜୀ ଅକ୍ଷର (fd;k) ସେଭ୍ କରେ ଏବଂ ଫଣ୍ଟ ସେଗୁଡ଼ିକୁ ହିନ୍ଦୀ ଶବ୍ଦ “କିୟା” ଭାବେ ଦେଖାଏ।
  • ୟୁନିକୋଡ୍ (Mangal, Nirmala UI, Noto) ପ୍ରକୃତ ହିନ୍ଦୀ ଅକ୍ଷର ସେଭ୍ କରେ, ତେଣୁ ପ୍ରତ୍ୟେକ ଫୋନ୍, ୱେବସାଇଟ୍ ଓ ସର୍ଚ୍ଚ ଇଞ୍ଜିନ୍ ସେଗୁଡ଼ିକୁ ପଢ଼ିପାରେ।
  • ଅନେକ ଅଫିସ୍, କୋର୍ଟ ଓ ଟାଇପିଂ ପରୀକ୍ଷା ଏବେ ବି କୃତିଦେବ ବ୍ୟବହାର କରନ୍ତି, ତେଣୁ କନଭର୍ଟର୍ ଓଲଟା ମଧ୍ୟ ଚାଲେ: “ୟୁନିକୋଡ୍ → କୃତିଦେବ”।
  • Kruti Dev 011, 016, 055 ଓ DevLys 010ରେ ମଧ୍ୟ Kruti Dev 010 ଭଳି ସମାନ କି ଅଛି, ତେଣୁ ସେଗୁଡ଼ିକ ମଧ୍ୟ ଏହିପରି ବଦଳେ।

ନୂଆ ମାଗଣା ଟୁଲ୍ ଓ ହିନ୍ଦୀରେ AI ପାଠ ପାଆନ୍ତୁ

ଆମ ଇମେଲ୍ ତାଲିକାରେ ଯୋଗ ଦିଅନ୍ତୁ: ନୂଆ ମାଗଣା ଆପ୍, ନୂଆ ଗାଇଡ୍ ଓ AI ଉପରେ ହିନ୍ଦୀ ଭିଡିଓ ପାଠର ଖବର ଆପଣ ପାଇବେ। କୌଣସି ସ୍ପାମ୍ ନାହିଁ।

✉️ ମାଗଣା ଇମେଲ୍ ତାଲିକାରେ ଯୋଗ ଦିଅନ୍ତୁ

କେବଳ ବୟସ୍କଙ୍କ (18+) ପାଇଁ। ଆପଣ ଯେକୌଣସି ସମୟରେ ନାମ ହଟାଇ ପାରିବେ।

ଆମେ ଏହି ଟୁଲ୍ କାହିଁକି ପରାମର୍ଶ ଦେଉ

  • ସମସ୍ତଙ୍କ ପାଇଁ ମାଗଣା: ବିଜ୍ଞାପନ ନାହିଁ, ସାଇନ୍-ଅପ୍ ନାହିଁ, ପେଡ୍ ପ୍ଲାନ୍ ନାହିଁ।
  • ବ୍ୟକ୍ତିଗତ: ଆପଣଙ୍କ ଫାଇଲ୍ ଓ ତଥ୍ୟ ଆପଣଙ୍କ ନିଜ ଡିଭାଇସ୍‌ରେ ହିଁ ରହେ।
  • ଫୋନ୍, ଲାପଟପ୍ କିମ୍ବା ସ୍ମାର୍ଟବୋର୍ଡରେ ଚାଲେ, ଏବଂ ଥରେ ଖୋଲିବା ପରେ ଇଣ୍ଟରନେଟ୍ ବିନା ମଧ୍ୟ।
  • ଓଡ଼ିଆ ଓ ହିନ୍ଦୀ ସମେତ 12ଟି ଭାଷାରେ।

ଭିଡିଓରୁ ଶିଖିବା ଭଲ ଲାଗେ? ଆମ YouTube ଚ୍ୟାନେଲରେ AI ଓ ମାଗଣା ଟୁଲ୍‌ର ହିନ୍ଦୀ ପାଠ ଦେଖନ୍ତୁ।

▶ YouTubeରେ ସବସ୍କ୍ରାଇବ୍ କରନ୍ତୁ

ବାରମ୍ବାର ପଚରାଯାଉଥିବା ପ୍ରଶ୍ନ

କୃତିଦେବକୁ Mangal ଫଣ୍ଟକୁ କିପରି ବଦଳାଇବେ?

Mangal ଏକ ୟୁନିକୋଡ୍ ଫଣ୍ଟ। ଲେଖାକୁ କୃତିଦେବରୁ ୟୁନିକୋଡ୍‌କୁ ବଦଳାନ୍ତୁ, Wordରେ ପେଷ୍ଟ କରନ୍ତୁ ଏବଂ ଫଣ୍ଟ Mangal କିମ୍ବା Nirmala UI ରଖନ୍ତୁ।

ଏହା କ'ଣ ମରାଠୀ ଓ ସଂସ୍କୃତ ପାଇଁ ମଧ୍ୟ ଚାଲେ?

ହଁ। ଏହା ମରାଠୀର ବିଶେଷ ଅକ୍ଷର ମଧ୍ୟ ବଦଳାଏ, ଏବଂ ଏଥିରେ ସଂସ୍କୃତର ଏକ ବିକଳ୍ପ ଅଛି, ଯେଉଁଥିରେ ଶବ୍ଦ ଶେଷର % ସର୍ବଦା ବିସର୍ଗ ହୁଏ।

ମୋ ଲେଖା କ'ଣ ସୁରକ୍ଷିତ?

ହଁ। ବଦଳ ଆପଣଙ୍କ ଡିଭାଇସ୍‌ରେ ହିଁ ହୁଏ। କିଛି ଅପଲୋଡ୍ ହୁଏ ନାହିଁ, ତେଣୁ ଆଇନଗତ, କୋର୍ଟ ଓ ସରକାରୀ ଖସଡ଼ା ପାଇଁ ଏହା ସୁରକ୍ଷିତ।

କିଛି ଅକ୍ଷର ଲାଲ୍ କାହିଁକି ରହିଯାଏ?

ସେଗୁଡ଼ିକ Kruti Dev 010 କିବୋର୍ଡର ଅଂଶ ନୁହେଁ; ଅନେକ ସମୟରେ ସେଗୁଡ଼ିକ Chanakya ଭଳି ଅନ୍ୟ ଫଣ୍ଟ କିମ୍ବା ଖରାପ ଫାଇଲରୁ ଆସେ। ସେଗୁଡ଼ିକୁ ହାତରେ ଠିକ୍ କରନ୍ତୁ।

ୟୁନିକୋଡ୍‌କୁ କ'ଣ ପୁଣି କୃତିଦେବକୁ ବଦଳାଇହେବ?

ହଁ। “ୟୁନିକୋଡ୍ → କୃତିଦେବ” ବାଛନ୍ତୁ, ହିନ୍ଦୀ ଲେଖା ପେଷ୍ଟ କରନ୍ତୁ, ଫଳ କପି କରନ୍ତୁ ଏବଂ Word, PageMaker କିମ୍ବା CorelDRAWରେ ଫଣ୍ଟ Kruti Dev 010 ରଖନ୍ତୁ।
