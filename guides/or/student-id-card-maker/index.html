ହୋମ୍/ଗାଇଡ୍/ଛାତ୍ର ID କାର୍ଡ ମେକର୍
ମାଗଣା, ସହଜ ଗାଇଡ୍

ଛାତ୍ର ID କାର୍ଡ ମେକର୍: ମାଗଣାରେ ID କାର୍ଡ ତିଆରି କରି A4 ରେ ପ୍ରିଣ୍ଟ କରନ୍ତୁ

ଛୋଟ ସ୍କୁଲ, କୋଚିଂ କ୍ଲାସ୍ କିମ୍ବା କୌଣସି କାର୍ଯ୍ୟକ୍ରମର ID କାର୍ଡ ତିଆରି କରିବାକୁ ଡିଜାଇନ୍ ସଫ୍ଟୱେର୍ ଦରକାର ନାହିଁ। ଏହି ମାଗଣା ଆପ୍ ଆପଣ ଲେଖିଥିବା ତଥ୍ୟରୁ କାର୍ଡ ତିଆରି କରିଦିଏ, ଆଉ ପିଲାଙ୍କ ଫଟୋ ଆପଣଙ୍କ ଡିଭାଇସ ବାହାରକୁ ଯାଏ ନାହିଁ।

ଅପଡେଟ୍: 14 ନଭେମ୍ବର 2026 · ପଢ଼ିବାକୁ 4 ମିନିଟ୍

🪪 ID କାର୍ଡ ମେକର ଖୋଲନ୍ତୁ (ମାଗଣା) ପଦକ୍ଷେପ ଦେଖନ୍ତୁ ↓

ସଂକ୍ଷିପ୍ତ ଉତ୍ତର

ID କାର୍ଡ ମେକର ଖୋଲନ୍ତୁ, “ଛାତ୍ରଛାତ୍ରୀ” ବାଛନ୍ତୁ ଓ ସ୍କୁଲର ନାମ ଆଉ ଛାତ୍ରଛାତ୍ରୀଙ୍କ ତଥ୍ୟ ଲେଖନ୍ତୁ। ଫଟୋ ଲଗାଇବାକୁ “ଫଟୋ ବାଛନ୍ତୁ” ଦବାନ୍ତୁ। ପୂରା ଶ୍ରେଣୀ ପାଇଁ “ଅନେକ କାର୍ଡ (ତାଲିକା)” ବାଛି ତାଲିକା ପେଷ୍ଟ କରନ୍ତୁ। ତା’ପରେ “A4 ରେ ଛାପନ୍ତୁ” ଦବାନ୍ତୁ: ପ୍ରତି କାର୍ଡ 54 × 86 mm, ଆଉ ଗୋଟିଏ A4 ସିଟ୍‌ରେ 9ଟି ଠିଆ କିମ୍ବା 10ଟି ଶୁଆ କାର୍ଡ ରହେ।

5ଟି ପାଦରେ ଛାତ୍ର ID କାର୍ଡ

  1. କାର୍ଡର ପ୍ରକାର ବାଛି ସ୍କୁଲର ତଥ୍ୟ ଭରନ୍ତୁ

    ID କାର୍ଡ ମେକର ଖୋଲନ୍ତୁ। ଏହା ନମୁନା ତଥ୍ୟ ସହ ଖୋଲେ। “ଛାତ୍ରଛାତ୍ରୀ” ବାଛନ୍ତୁ (“କର୍ମଚାରୀ” ଓ “ଅତିଥି” ମଧ୍ୟ ଅଛି)। ସ୍କୁଲର ନାମ, ଠିକଣା, ଯୋଗାଯୋଗ ନମ୍ବର ଓ କାର୍ଡ କେବେ ପର୍ଯ୍ୟନ୍ତ ବୈଧ ତାହା ଲେଖନ୍ତୁ। ଲୋଗୋ ଥିଲେ “ଲୋଗୋ ବାଛନ୍ତୁ” ଦବାନ୍ତୁ।

  2. ଛାତ୍ରଛାତ୍ରୀଙ୍କ ତଥ୍ୟ ଓ ଫଟୋ ଯୋଡ଼ନ୍ତୁ

    “ଗୋଟିଏ କାର୍ଡ” ବଛା ଥିବା ଅବସ୍ଥାରେ ନାମ, ଶ୍ରେଣୀ ଓ ସେକ୍ସନ୍ ଆଉ ID ନମ୍ବର ଲେଖନ୍ତୁ। ରକ୍ତ ଗ୍ରୁପ୍ କାର୍ଡରେ ଦରକାର ହେଲେ ତାହା ବାଛନ୍ତୁ। “ଫଟୋ ବାଛନ୍ତୁ” ଦବାନ୍ତୁ, ମୁହଁର ସ୍ପଷ୍ଟ ଫଟୋ ବାଛନ୍ତୁ ଓ ମୁହଁ ଫ୍ରେମ୍‌ର ମଝିରେ ନ ଆସିବା ପର୍ଯ୍ୟନ୍ତ ସ୍ଲାଇଡର୍ ଘୁଞ୍ଚାନ୍ତୁ।

  3. ପୂରା ଶ୍ରେଣୀର କାର୍ଡ ତିଆରି କରନ୍ତୁ

    “ଅନେକ କାର୍ଡ (ତାଲିକା)” ବାଛନ୍ତୁ ଓ ପ୍ରତି ଧାଡ଼ିରେ ଜଣେ ଛାତ୍ର ଲେଖନ୍ତୁ କିମ୍ବା ପେଷ୍ଟ କରନ୍ତୁ: ନାମ, ଶ୍ରେଣୀ, ID ନମ୍ବର, ରକ୍ତ ଗ୍ରୁପ୍, କେବେ ପର୍ଯ୍ୟନ୍ତ ବୈଧ, ଯୋଗାଯୋଗ, ଠିକଣା। କେବଳ ନାମ ନିହାତି ଦରକାର, ଆଉ Excel ରୁ ମଧ୍ୟ ପେଷ୍ଟ କରିହେବ। “ନମୁନା CSV ଡାଉନଲୋଡ୍ କରନ୍ତୁ” ରୁ ଢାଞ୍ଚା ବୁଝିହୁଏ। ଫଟୋ ଫାଇଲ୍‌ର ନାମ ID ନମ୍ବର କିମ୍ବା ନାମ ଅନୁସାରେ ଦିଅନ୍ତୁ ଓ “ଫଟୋ ଯୋଡ଼ନ୍ତୁ” ଦ୍ୱାରା ସବୁ ଏକାଠି ଯୋଡ଼ନ୍ତୁ।

  4. ଡିଜାଇନ୍ ବାଛନ୍ତୁ

    “ଠିଆ” କିମ୍ବା “ଆଡ଼” ଓ ଗୋଟିଏ ରଙ୍ଗ ବାଛନ୍ତୁ। ID ନମ୍ବର ଥିବା QR କୋଡ୍ ଦରକାର ହେଲେ “ID ନମ୍ବରର QR କୋଡ୍ ଯୋଡ଼ନ୍ତୁ” ରେ ଚିହ୍ନ ଦିଅନ୍ତୁ।

  5. A4 ରେ ପ୍ରିଣ୍ଟ କରନ୍ତୁ କିମ୍ବା ଡାଉନଲୋଡ୍ କରନ୍ତୁ

    “A4 ରେ ଛାପନ୍ତୁ” ଦବାନ୍ତୁ। ପ୍ରିଣ୍ଟ ୱିଣ୍ଡୋରେ A4 କାଗଜ ଓ 100% ସ୍କେଲ୍ ବାଛନ୍ତୁ, ତା’ପରେ ଛୋଟ ଚିହ୍ନ ଅନୁସାରେ କାଟନ୍ତୁ। “PNG ଡାଉନଲୋଡ୍ କରନ୍ତୁ” ଦ୍ୱାରା କାର୍ଡଟି ଛବି ଭାବେ ସେଭ୍ ହୁଏ।

ID କାର୍ଡ ଛାପିବା ପାଇଁ ପରାମର୍ଶ

  • ମୋଟା A4 କାଗଜରେ ଛାପନ୍ତୁ। ତା’ପରେ କାର୍ଡ ଲାମିନେଟ୍ କରନ୍ତୁ କିମ୍ବା କାର୍ଡ ହୋଲ୍ଡରରେ ରଖନ୍ତୁ।
  • ଏବେ ଫଟୋ ନାହିଁ? କାର୍ଡରେ ପ୍ରାୟ 20 × 25 mm ର ଖାଲି ଫ୍ରେମ୍ ଆସେ, ସେଠାରେ ଷ୍ଟାମ୍ପ ସାଇଜ୍ ଫଟୋ ଲଗାଇପାରିବେ।
  • ଗୋଟିଏ ତାଲିକାରେ 300ଟି ପର୍ଯ୍ୟନ୍ତ କାର୍ଡ ହୋଇପାରେ। ବଡ଼ ସ୍କୁଲ ପାଇଁ ପ୍ରତି ଶ୍ରେଣୀର ଅଲଗା ତାଲିକା କରନ୍ତୁ।
  • ପୂରା ସିଟ୍ ଛାପିବା ଆଗରୁ ସ୍କ୍ରିନ୍‌ରେ ବନାନ, ID ନମ୍ବର ଓ ଯୋଗାଯୋଗ ନମ୍ବର ଯାଞ୍ଚ କରନ୍ତୁ। କୌଣସି ID ନମ୍ବର ଦୁଇଥର ଆସିଲେ ଆପ୍ ଜଣାଇଦିଏ।

ନୂଆ ମାଗଣା ଟୁଲ୍ ଓ ହିନ୍ଦୀରେ AI ପାଠ ପାଆନ୍ତୁ

ଆମ ଇମେଲ୍ ତାଲିକାରେ ଯୋଗ ଦିଅନ୍ତୁ: ନୂଆ ମାଗଣା ଆପ୍, ନୂଆ ଗାଇଡ୍ ଓ AI ଉପରେ ହିନ୍ଦୀ ଭିଡିଓ ପାଠର ଖବର ଆପଣ ପାଇବେ। କୌଣସି ସ୍ପାମ୍ ନାହିଁ।

✉️ ମାଗଣା ଇମେଲ୍ ତାଲିକାରେ ଯୋଗ ଦିଅନ୍ତୁ

କେବଳ ବୟସ୍କଙ୍କ (18+) ପାଇଁ। ଆପଣ ଯେକୌଣସି ସମୟରେ ନାମ ହଟାଇ ପାରିବେ।

ଆମେ ଏହି ଟୁଲ୍ କାହିଁକି ପରାମର୍ଶ ଦେଉ

  • ସମସ୍ତଙ୍କ ପାଇଁ ମାଗଣା: ବିଜ୍ଞାପନ ନାହିଁ, ସାଇନ୍-ଅପ୍ ନାହିଁ, ପେଡ୍ ପ୍ଲାନ୍ ନାହିଁ।
  • ବ୍ୟକ୍ତିଗତ: ଆପଣଙ୍କ ଫାଇଲ୍ ଓ ତଥ୍ୟ ଆପଣଙ୍କ ନିଜ ଡିଭାଇସ୍‌ରେ ହିଁ ରହେ।
  • ଫୋନ୍, ଲାପଟପ୍ କିମ୍ବା ସ୍ମାର୍ଟବୋର୍ଡରେ ଚାଲେ, ଏବଂ ଥରେ ଖୋଲିବା ପରେ ଇଣ୍ଟରନେଟ୍ ବିନା ମଧ୍ୟ।
  • ଓଡ଼ିଆ ଓ ହିନ୍ଦୀ ସମେତ 12ଟି ଭାଷାରେ।

ID କାର୍ଡର ଆକାର କେତେ?

ପ୍ରତି କାର୍ଡ 54 × 86 mm, ପ୍ରାୟ ବ୍ୟାଙ୍କ କାର୍ଡ ଭଳି, ତେଣୁ ସାଧାରଣ କାର୍ଡ ହୋଲ୍ଡରରେ ରହିଯାଏ। ଏହି ଆକାର ରଖିବାକୁ 100% ସ୍କେଲ୍‌ରେ ଛାପନ୍ତୁ।

ଗୋଟିଏ A4 ପୃଷ୍ଠାରେ କେତୋଟି ID କାର୍ଡ ରହେ?

9ଟି ଠିଆ କାର୍ଡ କିମ୍ବା 10ଟି ଶୁଆ କାର୍ଡ। ଆପଣଙ୍କ ତାଲିକା ପାଇଁ କେତୋଟି ପୃଷ୍ଠା ଲାଗିବ, ଆପ୍ ଦେଖାଏ।

ସବୁ ଛାତ୍ରଛାତ୍ରୀଙ୍କ ID କାର୍ଡ ଏକାଥରେ ତିଆରି ହେବ କି?

ହଁ। “ଅନେକ କାର୍ଡ (ତାଲିକା)” ବାଛି ତାଲିକା ପେଷ୍ଟ କରନ୍ତୁ, କିମ୍ବା “CSV ଫାଇଲ୍ ଖୋଲନ୍ତୁ” ଦ୍ୱାରା CSV ଫାଇଲ୍ ଖୋଲନ୍ତୁ। ସବୁ ଫଟୋ ଏକାଠି ଯୋଡ଼ନ୍ତୁ: ସେଗୁଡ଼ିକ ID ନମ୍ବର କିମ୍ବା ନାମ ଅନୁସାରେ ନିଜେ ମିଳିଯାଏ।

ଛାତ୍ରଛାତ୍ରୀଙ୍କ ଫଟୋ ଅପଲୋଡ୍ ହୁଏ କି?

ନା। ଫଟୋ ଓ ତଥ୍ୟ ଆପଣଙ୍କ ଡିଭାଇସରେ ହିଁ ରହେ; କିଛି ଅପଲୋଡ୍ ହୁଏ ନାହିଁ। କାର୍ଡ ଆପଣଙ୍କ ନିଜ ବ୍ରାଉଜରରେ ତିଆରି ହୁଏ।

ଏହା ସରକାରୀ ପରିଚୟପତ୍ର କି?

ଏହା ଆପଣଙ୍କ ନିଜ ସ୍କୁଲ, କ୍ଲାସ୍, ଅଫିସ୍ କିମ୍ବା କାର୍ଯ୍ୟକ୍ରମର ପରିଚୟପତ୍ର। ଏହା ସରକାରୀ ID ନୁହେଁ, ଆଉ ଏହାକୁ କେବଳ ସ୍କୁଲ କିମ୍ବା ଆୟୋଜକ ହିଁ ତିଆରି କରିବା ଉଚିତ।
